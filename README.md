この文書は「完成品」ではありません。意見を受けて、検証して、直していく前提で公開しています。

## この文書の約束

- 政策は、葛飾での実践と検証（PDCA）を通じて更新します
- 寄せられた意見は、分類・可視化のうえで公開し、採用したもの・見送ったものと、その理由を返します
- 最終的な判断は、本人が行います
